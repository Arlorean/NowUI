# NowUI Standalone Core — Unity Dependency Inventory

Historical inventory used to design the M1 engine shim. Source line numbers and
browser-specific recommendations below are preserved as research evidence;
the original standalone WASM host and JavaScript authoring API were retired.
Current native usage and the optional shared C# browser target are documented
in [Native CLI](NativeCLI.md).

Source of truth for the next design phase (shim spec, render-backend interface, file split). Synthesised from 171 per-file reader reports (all of `Runtime/` incl. `URP/` and `HDRP/`, and all of `Extensions/`) plus the assembly-structure report. Line numbers are those quoted by the readers. Nothing below is invented beyond what the reports contain; where readers disagreed or hedged, the disagreement is recorded rather than resolved.

Conventions: **core** = compiles against the shim unchanged; **core-with-guards** = needs a few `#if` regions or a small hook; **split-file** = classes/members move to a Unity host partial/file; **host-only-exclude** = excluded from the core build.

---

## H. Open questions for the design phase (ranked by plan impact)

1. **Does the shim ship a `UnityEngine.ScriptableObject`?** Gates NowFont/NowFontAsset, NowFontFamily, NowThemeAsset (+`ISerializationCallbackReceiver`), NowControlRenderer, NowMaterialControlRenderer, NowUnityEditorControlRenderer, NowLottieAsset, NowTheme.DefaultAsset. Public API literally says `NowFontAsset : ScriptableObject`; plan goal (b) forbids the dependency. Options: minimal shim base (name/hideFlags/CreateInstance/OnEnable-OnDisable-OnDestroy dispatch/isDestroyed) vs. `#if`-swapped base-class lists + factories. Also decides the standalone serialization format for fonts/themes.
2. **Now.cs screen path: host partial (`INowScreenBackend`) or shim emulation of `GL`/`Graphics.DrawMeshNow`/`RenderTexture.GetTemporary`/`CommandBuffer`?** Decides whether Now.cs is split-file or core-with-guards, and whether the WebGL2 backend needs an immediate-mode path in addition to the recorded-CommandBuffer path used by NowRenderer.
3. **Engine-free font pipeline.** NowManagedFontSession/NowManagedFontBaker (the "managed fallback") currently require Burst/Jobs/Mathematics/Collections; a sequential port of `NowSdfBakeJob.Execute` is required. Native nowui-msdf/HarfBuzz on wasm: link `__Internal` (needs HarfBuzz bundling and a .NET-wasm native reference) or disable (no ligatures/complex scripts). NowFontCompiler split point (`CreateFont` → `INowFontFactory`).
4. **How host-only classes referenced from core are cut**: interfaces/events (`INowNativeInputBridge`, `Now.materialReleased`, `INowOverlayHost`, `INowPointerOcclusion`, `object owningSelection`) vs. a new `NOWUI_UNITY_HOST` define around ~30 sites (NowFont 2256, Now 1085, NowGradient 715, NowSdf 3548, NowInput ×12, NowTextInput, NowSurfaceToScreenMapper, NowOverlay, NowRaycastGate stubs, NowLottieRenderer ×3, NowInputSnapshot.FromCamera). Interfaces are API-neutral (all internal) but touch more files.
5. **Assembly shape**: single `NowUI.Runtime` compiled from core+host sources in Unity (partial classes, no InternalsVisibleTo change) vs. separate core + host assemblies (needs a new friend entry, `partial` classes cannot span assemblies — Now/NowLayout/NowOverlay/NowRaycastGate/NowLottieAsset/NowFontCompiler/NowInput host partials would have to become separate host classes or extension statics; NowKeyBindingField already extends `Now`/`NowLayout` partials from the host side).
6. **Gradient / AnimationCurve fidelity**: the shim must implement `Gradient.Evaluate` (Blend/Fixed/PerceptualBlend) and `AnimationCurve.Evaluate` (weighted Hermite, infinite tangents, wrap modes) exactly enough for gradient bakes and curve previews — or NowValueControls/NowInspector guard those controls.
7. **Standalone asset format and preload**: font export (atlas + glyph table + TTF bytes + material template), theme JSON vs. code defaults, which of the 16 shader programs + Sdf/Color Picker are ported first, `Resources.Load` provider registration, `NowFontFamily` population (no setters today).
8. **Feature scope for WebGL2 v1**: glass (needs backdrop copy/blur render-to-texture), Effects snapshots, SDF scenes (R8 mask RT) and SDF image fields (float RTs, 5-pass bake), Lottie (managed tessellator OK), ModelPreview (excluded), FilePicker (no filesystem), Markdown remote images/Lottie URLs (fetch + CORS).
9. **Clock/frame contract**: shim `Time` driven by the host vs. making `NowTime` the sole clock; who increments `frameCount`; whether `NowInputSnapshot`'s short constructors keep reading `Time` or hosts always use the 20-argument constructor.
10. **Coordinate conventions**: keep Unity's bottom-left `Screen.safeArea`/pointer pixel space in the shim (three flip sites: NowScreen 65, NowSurfaceToScreenMapper 85-88, NowScreenInputProvider 178, plus NowInputSnapshot 64-67) or convert the core to top-left and adapt the Unity host; bit-exact `Matrix4x4.Ortho` and the framebuffer y-flip.
11. **`DEVELOPMENT_BUILD` equivalent**: define it (or `NOWUI_DEV`) in the standalone Debug configuration so the guarded duplicate-id / leaked-scope / unparsed-tag diagnostics survive.
12. **Browser IO policy**: ship NowFilePicker/NowFilePickerUserFolders/NowMarkupFile/NowMarkup.File at all (in-memory `INowFileSystem`) or exclude them from the wasm build; `fetch` redirect handling vs. the manual per-hop policy; clipboard synchronous read contract.
13. **`NativeArray<T>` in public/internal signatures**: shim it (ctor/indexer/Length/IsCreated/Dispose/AsSpan/Copy) or change `Texture2D.GetRawTextureData<T>` to return `Span<T>` and `DynamicSession.TryCopyAtlas` to take `Span<byte>` (behaviour-neutral, public API of `NowFontCompiler` unchanged only if the NativeArray overload stays host-side).
14. **`QualitySettings.activeColorSpace` in the standalone**: only used by NowMesh canvas colour patching (UGUI-only) and NowModelPreview — constant Linear is probably fine, but the text/gradient shaders' colour-space includes (`NowUIColorSpace.cginc`) must match the backend's framebuffer.
15. **Reset strategy**: keep `[RuntimeInitializeOnLoadMethod]` as a no-op attribute and reflect over it once, or convert the 39 reset methods into a generated `NowRuntime.ResetAll()` registry (also covering the ~20 statics that have no reset today).
16. **Test project identity**: name it `Tests` to inherit all InternalsVisibleTo grants, and provide a null render backend so the ~525 pure-logic test attributes run under `dotnet test`.
17. **Culture**: invariant-globalization wasm build (NowDatePicker month names/first day, NowFilePicker ordering) — accept or ship ICU.
18. **Native ABI guarantees**: shim `Vector2/3/4`, `Color`, `Color32` must be sequential-float structs (NowLottieNative pins them); decide whether the shim also mirrors Unity's `[Serializable]` expectations for host-side `JsonUtility` round-tripping of node-graph classes.
